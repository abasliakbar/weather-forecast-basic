# WeatherNow 🌤️

A minimal and modern web application that provides real-time weather conditions for any city.

## Features

* **City Search:** Easily search and retrieve instant weather data for any city worldwide.
* **Live API Integration:** Accurate, real-time data powered by the OpenWeatherMap API.
* **Modern UI/UX:** Clean, dark-themed interface focused on modern aesthetics and readability.
* **Responsive Design:** Fully optimized across desktop and mobile screen sizes.

## Tech Stack

* **HTML5** – Page Structure
* **CSS3** – Styling & Custom UI Layout
* **JavaScript (ES6+)** – Logic & Fetch API Integration
* **OpenWeatherMap API** – Real-time Weather Data Provider
